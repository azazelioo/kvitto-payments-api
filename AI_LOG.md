# Работа с ИИ

Инструмент: Codex. Модель: GPT-6.1 Sol, уровень рассуждений — лёгкий.

Работал небольшими этапами: разбор требований, окружение, БД и миграции, расчёты, API, идемпотентность, вебхук, Docker и CI. Агенту передавались PDF, текущий код и правила AGENTS.md. После изменений кода запускались тесты и проверки ruff.

## Ключевые запросы

- «Прочитай PDF, выдели обязательные требования, бонусы и неоднозначности. Для каждого требования предложи способ проверки. Отделяй условия задания от собственных предположений. Пока не изменяй файлы».
- «Добавь идемпотентность POST /payments: новый ключ — 201, повтор — 200 и тот же платёж. Используй UNIQUE в БД, после конфликта выполняй rollback, не скрывай посторонние ошибки. Проверь параллельные запросы с независимыми сессиями и барьерами без sleep».
- «Добавь Docker Compose: миграции до запуска API, непривилегированный пользователь и SQLite в volume. Проверь сборку, создание платежа и получение той же записи после пересоздания контейнера. Невыполненные проверки не обозначай как успешные».

## Замеченные проблемы

- Агент первоначально работал в другой папке. Проверки pwd и git status показали несовпадение пути и отсутствие репозитория. Работу остановили и продолжили в нужном каталоге.
- Агент предложил запрещать запуск без WEBHOOK_SECRET. Это добавляло обязательную настройку ради бонусной функции. Решение изменили: пустой секрет отключает проверку подписи, непустой делает её обязательной; поведение описали в README.
- Ruff обнаружил длинные строки в тестах миграций. Форматирование исправили и проверки повторили.
- Pytest показал предупреждение Starlette об использовании httpx. Его не скрывали и не меняли зависимости без выяснения причины. Недоступный Docker daemon отдельно определили как проблему окружения: после запуска Colima контейнерные проверки продолжили.

## Результаты проверки

229 тестов прошли, осталось одно предупреждение зависимости. Ruff и pip check прошли. Проверены миграции, ограничения БД, конкурентные повторы и переходы статусов, HMAC и фильтры. Docker собран и запущен: пользователь непривилегированный, платёж сохранился после пересоздания контейнера. Первоначальный запуск GitHub Actions прошёл. Финальное ревью выявило ошибку форматирования Python-примера README: проверка ruff format --check завершилась с ошибкой, поэтому pytest в этом запуске CI был пропущен. Форматирование исправлено командой ruff format README.md; повторная проверка ruff format --check прошла. Повторно прошли 229 тестов (одно предупреждение Starlette) и ruff check. Итоговый успех CI после исправления пока не подтверждён.
